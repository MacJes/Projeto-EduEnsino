# EduEnsino — Sistema de Gerenciamento Escolar

## Sobre o projeto

O EduEnsino é um sistema simples de gerenciamento escolar desenvolvido em Python, com o objetivo de colocar em prática os conhecimentos adquiridos durante os estudos de programação.

O projeto funciona pelo terminal e permite gerenciar alunos, turmas, disciplinas, notas e faltas, além de gerar relatórios com o desempenho dos estudantes.

## Funcionalidades

- Cadastrar, visualizar e excluir alunos.
- Adicionar e remover turmas.
- Consultar e modificar disciplinas.
- Registrar notas e faltas dos alunos.
- Calcular médias e verificar a frequência.
- Gerar relatórios com os resultados escolares.

## Tecnologias utilizadas

- Python 3
- Visual Studio Code

## Conceitos aplicados

Durante o desenvolvimento, foram utilizados conceitos de programação como:

- Funções e modularização

## Como executar o projeto

1. Instale o Python 3 no computador.
2. Clone o repositório:

```bash
git clone https://github.com/MacJes/Projeto-EduEnsino.git
```

3. Acesse a pasta do projeto:

```bash
cd Projeto-EduEnsino
```

4. Execute o arquivo principal:

```bash
python Modularizacao.py
```

O sistema será iniciado no terminal, apresentando um menu com as funcionalidades disponíveis.

Não é necessário instalar bibliotecas externas.
